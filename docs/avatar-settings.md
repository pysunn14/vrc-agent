# 아바타 설정 만들기와 등록

아바타 설정 묶음은 골격, 기준 자세, 머리 기준 위치, 선택적인 표정 연결,
아바타 버전과 적용 조건을 담은 하나의 JSON 파일입니다.
구매한 모델, 텍스처, Unity 프로젝트, 계정 정보는 포함하지 않습니다.

## 이미 준비된 설정 사용하기

1. `vrc-agent configure`에서 아바타 설정을 선택합니다.
2. **준비된 아바타 설정 사용**을 선택하거나 **아바타 설정 묶음 가져오기**로 받은 파일을 선택합니다.
3. 이름, 버전, 적용 조건, 표정 지원을 읽고 적용합니다. 개별 골격·자세 경로는 묻지 않습니다.
4. 현재 환경에서 ARDY 추적을 켜고 실제 자세와 표정을 확인한 경우에만 확인 완료를 선택합니다.
   아직 확인하지 않았다면 나중에 이어서 진행합니다. 준비되지 않은 아바타는 실행 전 검사에서 차단됩니다.

Windows 브리지에는 에이전트와 같은 설정 묶음을 가져옵니다.
묶음에 담긴 골격과 머리 기준 위치가 함께 적용됩니다.
가져오기는 VRChat에 아바타를 업로드하거나 선택하는 작업을 수행하지 않습니다.

## 처음 만드는 아바타

1. [Unity 내보내기 도구](../native/unity_avatar_rig_exporter/README.md)를 설치합니다.
2. Unity의 Hierarchy에서 사용할 아바타를 선택하고
   `Tools > VRC Ardy > Export Selected Avatar Rig Profile`을 실행합니다.
   결과는 `Assets/VrcArdy/Generated/<avatar>.avatar-rig.json`에 저장됩니다.
3. `vrc-agent configure` → 아바타 → **내 아바타 설정 만들기**에서 내보낸 파일을 선택합니다.
4. 위자드가 골격에서 팔을 내린 기준 자세 후보를 만들고 초안에 보관합니다.
   자세 JSON을 직접 만들 필요는 없습니다. Windows가 꺼져 있다면 여기서 중단하고 나중에 이어갈 수 있습니다.
5. Windows에서 사용할 VRChat 계정과 아바타를 선택하고 브리지를 실행합니다.
   교정만 진행할 때는 Windows 브리지 실행 명령에 `--calibration-only`를 추가합니다.
   이 모드는 오디오·화면 캡처를 준비하지 않고 VRChat 대상과 자세 출력을 연결합니다.
6. 위자드에서 **지금 VRChat에서 기준 자세를 확인하고 조정**을 선택합니다.
   대화 에이전트나 다른 교정이 출력을 사용 중이면 먼저 종료해야 합니다.
7. 게임 화면을 보면서 양손 또는 한 손을 골라 위치를 1cm, 회전을 5도씩 조정합니다.
   골격에서 만든 후보가 모든 아바타에 맞는 것은 아닙니다. 손목 방향과 팔 위치를 직접 확인합니다.
8. **이 자세 확인 완료 · 저장**을 선택합니다. 추적이 켜진 상태에서 확인했다고 답한 경우에만
   해당 골격·자세의 확인 기록을 저장하고, 재사용할 아바타 설정 묶음으로 등록할 수 있습니다.

아바타 교정만 다시 시작하려면 `vrc-agent avatars calibrate`를 실행합니다.
연결 장비 설정이 있는 초안 또는 저장한 실행 설정을 사용하며, 결과는 초안에 저장됩니다.
실행 설정으로 적용하는 단계는 `vrc-agent configure`에서 마칩니다.

위치·회전 변경은 별도 자세 파일로 보관합니다. 취소하면 조정 초안을 남기고 Windows의
교정 전 안전 대기 출력으로 돌아갑니다. 이 대기 상태는 확인한 후보 자세와 다를 수 있습니다.
위자드가 사라지거나 연결이 끊기면 마지막 갱신으로부터 5초 뒤 교정을 해제합니다.
VRChat 대상이 바뀌면 교정을 다시 시작해야 합니다. 복귀에 실패하면 오류를 표시하고
다른 세션에 출력 권한을 넘기지 않습니다.

브리지가 관측하는 전송 완료는 출력 드라이버로의 전송입니다. 게임 안의 최종 자세나
VMT 장치 등록을 자동으로 확인했다는 뜻은 아닙니다. 추적이 꺼진 상태에서 보이는
VRChat 기본 자세를 교정 결과로 확인하면 안 됩니다.

## 관리와 공유

```sh
vrc-agent avatars list
vrc-agent avatars register
vrc-agent avatars export <목록의-key> avatar.avatar.json
vrc-agent avatars import avatar.avatar.json
```

`register`는 현재 초안이 있으면 초안의 아바타 설정을 사용하고, 없으면 저장한 설정을 사용합니다.
현재 파일과 일치하는 실제 동작 확인 기록이 필요합니다.
`import`는 목록에 등록합니다. 실행할 아바타의 변경은 `configure`에서 명시적으로 선택합니다.
`export`는 기존 파일을 덮어쓰지 않습니다.

사용자 등록 저장소는 실행 설정 파일과 같은 디렉터리의 `avatars/`입니다.
`avatars list --json`에서 실제 저장 위치를 확인할 수 있습니다.
같은 내용은 한 번만 등록하며, 변경된 내용은 별도 항목으로 보존합니다.
사용 중인 설정을 새 버전 가져오기로 덮어쓰지 않습니다.

기본 제공 설정은 Python 패키지의 `avatar_presets/*.avatar.json`에서 읽습니다.
완전한 설정 묶음만 이곳에 포함합니다. `rig_profiles/`의 골격 자료만으로
준비된 설정에 자동 등록하지 않습니다. 현재 배포 가능한 기본 설정 묶음은 없습니다.
기존 특정 환경의 교정 기록을 다른 사용자에게 검증 완료로 배포하지 않기 때문입니다.

## 파일 검사와 실제 확인의 차이

묶음 안에는 개인 환경의 확인 기록을 넣지 않습니다.
가져온 뒤에는 항상 현재 환경에서의 실제 동작 확인이 필요합니다.
골격·기준 자세·머리 기준 위치·표정 연결을 변경하면 기존 확인 기록이 무효화됩니다.
파일이 손상되면 목록의 문제 항목으로 표시하며 자동으로 다른 설정을 대신 적용하지 않습니다.

## 설정 묶음 형식

버전 1은 `version`, `name`, `avatar_version`, `conditions`, `rig`, `base_pose`,
`hmd_base`, `face_channels`를 포함합니다. `rig`와 `base_pose`는 경로가 아닌
실제 JSON 객체입니다. `calibration`은 이 형식에 포함되지 않습니다.
프로그램이 검증한 설정으로 묶음을 생성하므로 사용자가 직접 작성할 필요는 없습니다.
